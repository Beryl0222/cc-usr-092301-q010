# 碎片文化消费节律保护

家庭数字内容服务的「可解释使用节律」领域资料与参考核心：家长、青少年与学校
共同约定短视频、阅读、课程等不同内容类别的使用节律，而不是把所有使用粗暴
算成同一种时长。资料只包含领域约定与可本地运行的参考实现，不含真实个人
信息、生产连接或外部账号。

## 目录

- `src/culture_time_budget.js`：事件信封、事件目录与按种类的最小负载校验。
- `src/time_slices.js`：IANA 时区换算、本地日期归属、跨午夜会话切分、每日
  时间窗、上学日判定。不依赖 Temporal，夏令时春令时空档/秋令时重叠均可
  解释地解析。
- `src/policy.js`：带版本与生效期的政策模型，按成员/设备/内容类别/上学日
  选择最具体的适用修订。
- `src/rhythm_service.js`：事件溯源的核心服务（重放建态、乐观锁改策、
  幂等账本、漂移夹取、延长审批、限期例外、干预解释、撤权留存、学校汇总）。
- `data/sample.json`：用于核对信封格式的虚构事件（基线资料，保持兼容）。
- `tests/`：合同、时区切分、政策与核心服务的一致性测试。

## 事件目录

信封字段：`event_id`、`kind`、`occurred_at`（时刻，带偏移）、`subject_id`、
`payload`。`validateContractEvent` 在信封之外按种类校验最小负载。

| 事件 | 含义 |
| --- | --- |
| `BUDGET_SET` / `LIMIT_REACHED` | 基线事件，保留兼容历史资料 |
| `POLICY_SET` | 政策修订；含 `policy_id`、单调 `version`、`expected_version`（乐观并发）、`scope`、`time_zone`、按类别的 `daily_limits_seconds`、`windows`、`effective_from/to` |
| `CONSUMPTION_RECORDED` | 设备上报的一次使用；含设备窗口 `started_at/ended_at`、内容类别，以及离线补传用的 `server_window`（首报时刻、最大时钟偏差） |
| `DAY_RESET` | 调度器在成员本地日期零点写入的幂等重置标记 |
| `EXTENSION_REQUESTED` / `EXTENSION_APPROVED` / `EXTENSION_DECLINED` | 临时延长：成员提出、监护人批准；批准范围只能窄于申请，`valid_until` 不得晚于申请到期 |
| `EXCEPTION_GRANTED` / `EXCEPTION_REVIEWED` | 紧急联系、已下载课程等限期例外；硬性 `expires_at`，复核可撤销，到期由调度器补 `expired` |
| `INTERVENTION_RAISED` | 提醒或阻断；`basis` 携带政策版本、本地日期、时间片、限额/已用秒数、延长与贡献记录，可逐条解释 |
| `PROFILE_WITHDRAWN` | 撤回画像授权，其后停止生成个性化建议 |
| `RETENTION_ANNOTATED` | 为结算争议标注的最小留存记录与保留字段、保留期限 |
| `SCHOOL_SUMMARY_SHARED` | 向学校共享约定范围内、按日按类别聚合到分钟的汇总 |

## 核心约定

- **按成员本地时区计日**：使用会话按本地日期边界切分；春令时 23 小时日、
  秋令时 25 小时日的切分都以真实本地零点时刻为准，秒数守恒。
- **离线补传与时钟漂移不重复扣减**：先由设备时间 ± 最大偏差与服务器首报
  时刻夹出可行发生区间，再按「同设备区间并集」入账；同一 `record_id`
  重传原样返回首次结论。
- **并发改策检测版本冲突**：两位监护人同时修改时，基于旧
  `expected_version` 的提交抛 `PolicyConflictError`，重读最新版本后才能提交。
- **延长与例外都不是永久绕过**：延长有申请-批准-到期链路；例外必须显式
  声明用途（普通短视频不会被紧急联系例外顺带豁免），到期或撤销即时失效。
- **撤权与留存并存**：撤权后个性化建议停止；结算争议所需记录经
  `RETENTION_ANNOTATED` 声明后仅保留最小字段，其余明细脱敏。
- **学校只收约定汇总**：仅共享协议内成员与类别、按日按类别的分钟数，
  不含设备、记录标识与例外细节。
- **重启一致**：状态全部由事件重放得到；定时重置、待审批延长、离线合并
  区间与干预标记在重启后完全一致，调度器重复运行幂等。
